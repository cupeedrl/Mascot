# Mascot — Local Development Guide

This guide provides setup instructions, dependency management steps, testing commands, and development workflows for contributing to Mascot.

---

## 1. Prerequisites

- **Python**: 3.11 to 3.14
- **Node.js**: 22.12+ and npm
- **Docker Desktop**: Docker Compose v2 (recommended for PostgreSQL)

---

## 2. Quick Setup

### Step 1: Clone Repository & Create Environment Files
```bash
git clone https://github.com/your-username/Mascot.git
cd Mascot

# Copy environment variable templates
cp .env.example .env
cp backend/.env.example backend/.env
cp frontend/.env.example frontend/.env
```

### Step 2: Start Local PostgreSQL
```bash
docker compose up -d db
```

### Step 3: Setup Backend Environment
```bash
cd backend
python -m venv .venv

# On Windows PowerShell:
.\.venv\Scripts\Activate.ps1
# On Linux / macOS:
# source .venv/bin/activate

pip install --upgrade pip
pip install -e ".[dev]"
```

### Step 4: Run Database Migrations
```bash
python -m alembic upgrade head
```

### Step 5: Start Backend Development Server
```bash
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```
- API Docs: `http://localhost:8000/docs`
- Health check: `http://localhost:8000/api/v1/health`

### Step 6: Setup Frontend (Separate Terminal)
```bash
cd frontend
npm ci
npm run dev
```
- Frontend Web App: `http://localhost:5173`

## 3. Automated Testing

### Backend Test Suite (Pytest)
The test suite runs against in-memory SQLite instances for rapid, isolated execution without external API dependencies:

```bash
cd backend
pytest -q
```

## 4. Admin Account Management

To promote a registered user account to Administrator:

```bash
cd backend
python scripts/set_admin.py your-email@example.com
```

Once promoted, log in at `http://localhost:5173/login` and navigate to `/admin`.

## 5. Database Migration Commands

```bash
cd backend

# Apply all pending migrations
python -m alembic upgrade head

# Show current migration revision
python -m alembic current

# Show revision history
python -m alembic history

# Create a new autogenerated migration
# python -m alembic revision -m "description_of_change"
```
